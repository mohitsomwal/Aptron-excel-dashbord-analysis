# Aptron Training Institute Dashboard

## Project Overview
This Excel dashboard project provides an analytical overview of Aptron Training Institute courses, pricing, and organizational highlights. The dashboard is designed to visualize course fee comparisons, course category distribution, student training statistics, and organizational achievements using interactive Excel charts and dashboards.

---

## Dashboard Features

- Course Fees Comparison
- Course Category Distribution
- Organization Highlights Visualization
- Student Training Insights
- Placement Support Metrics
- Interactive Filters and Charts
- Professional Dashboard Design

---

## Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Data Visualization

---

## Key Insights

- CAD Training, Digital Marketing, and Graphic Design courses have the highest fee structure.
- The organization has trained over 10,000 students.
- Placement support and professional training metrics highlight strong institutional performance.
- Interactive charts improve data understanding and reporting.
